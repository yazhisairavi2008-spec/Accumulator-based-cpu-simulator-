📖 About

A live, interactive simulator that shows how a CPU fetches, decodes and executes instructions, one stage at a time. Type your own assembly program, press Step or Run, and watch the PC, IR, ACC, OUT registers and memory change.

Nothing is hardcoded. Every change you make to the program is assembled and loaded into memory when you press Assemble.

🔌 CPU Architecture

BlockRole
Memory256 × 8-bit locations (00–FF) holding the program and the data
PC (Program Counter)Points to the next instruction's address
IR (Instruction Register)Holds the instruction being worked on
Control UnitDecodes the opcode and directs the other blocks
ALUDoes the arithmetic and logic (ADD, SUB, AND, OR)
ACC (Accumulator)8-bit register that holds the ALU operand and result
OUTOutput register that receives ACC on the OUT instruction

🔄 The Instruction Cycle

StageWhat happens
1. FetchThe instruction at address PC is copied from memory into IR, and PC moves on by one
2. DecodeThe Control Unit identifies the opcode; if needed the next byte is read as the address operand
3. ExecuteThe ALU, ACC or memory carry out the operation
4. RepeatThe cycle repeats with the new PC until HALT

✨ Features

  • ⌨️ Write any program, and it loads as you assemble
  • 👣 Step through Fetch, Decode and Execute
  • 🗂️ 256-byte memory view with PC, read and write highlighting
  • 🎞️ Animated data path: PC → Memory → IR → Decoder → ALU/ACC → OUT
  • 🚦 Running / Paused / Halted CPU state
  • ▶️ Run, Pause, Reset and a speed slider
  • 📜 Trace log of every stage
  • ❗ Clear error messages with line numbers (invalid instruction, bad address, code/data overlap)

📋 Supported Instructions

InstructionOpcodeWhat it does
LOAD a01ACC = Memory[a]
STORE a02Memory[a] = ACC
ADD a03ACC = ACC + Memory[a]
SUB a04ACC = ACC - Memory[a]
AND a05Bitwise AND with Memory[a]
OR a06Bitwise OR with Memory[a]
JMP a07PC = a
OUT08OUT = ACC
HALTFFStop execution
Values are 8-bit (00–FF) and wrap around at 256. Numbers are hex (#12 for decimal). Text after ; is a comment. @addr value stores a data byte.

🧪 Example

LOAD 20     ; ACC = 05
ADD 21      ; ACC = 08
STORE 30    ; Memory[30] = 08
OUT         ; OUT = 08
HALT

@20 05
@21 03

Final result: Memory[20] = 05, Memory[21] = 03, ACC = 08, OUT = 08, Memory[30] = 08

🚀 Run it yourself

Open cpu-simulator.html in any modern browser. No installation, server or internet connection is needed.

🎯 Objectives

  • Simulate the basic instruction execution process of a CPU
  • Demonstrate the fetch-decode-execute cycle
  • Visualize registers, memory and the data path
  • Show how assembly becomes machine code in memory

🎓 Applications

  • Helps students understand how a CPU works inside
  • Useful for learning Computer Organization and Architecture concepts
  • Easy to extend with more instructions, such as conditional jumps
